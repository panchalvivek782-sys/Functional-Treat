## # Data Analyzer and Transformer Program
## 
## ## Description
## This Python project is an interactive, command-line tool designed for array processing and numerical analysis.
## It enables users to upload a custom 1D array of integers and run basic mathematical transformations.
## The program serves as a practical showcase for core concepts like lambda logic, array sorting, recursion, and multiple-value returns.
## 
## ## Key Programming Concepts Covered
## * **Functional Programming**: Uses `filter()` combined with `lambda` expressions to screen and sort numerical sequences dynamically.
## * **Mathematical Recursion**: Employs a custom self-referencing algorithm to accurately calculate the factorial of a specified integer.
## * **Tuple Unpacking**: Implements Python function returns to deliver and split multiple calculated statistics at the same time.
## * **Array Manipulation**: Modifies datasets in-place using built-in array methods to sort numbers in ascending or descending orders.
## 
## ## How to Run
## 1. Check that you have Python set up correctly on your operating system.
## 2. Copy the script code directly into a blank file named `data_analyzer.py`.
## 3. Launch your terminal application or standard command prompt window.
## 4. Run the module by executing this terminal statement: `python data_analyzer.py`
## 
## ## Interactive Menu Options
## * **Option 1**: Input Data (takes a string of numbers separated by spaces and saves them as an array).
## * **Option 2**: Display Data Summary (prints quick calculations like len, min, max, sum, and average).
## * **Option 3**: Calculate Factorial (solves the mathematical factorial calculation using recursive function cycles).
## * **Option 4**: Filter Data by Threshold (isolates numbers from your main array that cross a selected numeric ceiling).
## * **Option 5**: Sort Data (organizes elements of the internal array in either low-to-high or high-to-low order).
## * **Option 6**: Display Dataset Statistics (displays summary data using decoupled multiple-value return outputs).
## * **Option 7**: Exit Program (terminates the script safely and triggers a standard system exit command).
